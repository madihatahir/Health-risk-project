# Health Risk Prediction using ML/DL

## Overview
This project predicts early health risk using physiological and omics data using deep learning models (LSTM + VAE + Fusion Network).

## Models
- LSTM for time-series physiological signals
- VAE for omics feature learning
- Fusion network for risk prediction

## Dataset
- MIMIC-IV / NASA OSDR (or synthetic test data)

## Output
- Risk score (0–1)
- Early disease prediction

## How to run
python train.py
